# DocuStyle

## For Users — How to Run

1. Make sure Python is installed (python.org — check "Add Python to PATH")
2. Double-click **Launch.bat**
3. A browser window opens automatically with the app
4. To close the app, close the black launcher window

## For You — How to Change the Style

Open `app.py` in any text editor (Notepad is fine).

At the top of the file you'll see a section labeled **STYLE SETTINGS**.
Change any values there and save the file. Next time someone launches the app the new style will be applied to all documents.

## Distributing to Others

Send users the whole folder containing:
- app.py
- Launch.bat
- README.md

They just need Python installed and then double-click Launch.bat.
